# Embee Client Onboarding

Next.js app for Embee debt-case intake: admin dashboard, extraction review, client portal, mandate/NDA, funder matching, and two-pager preview.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
